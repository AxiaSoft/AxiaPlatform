The admin console runs on the server build.

This deployment is the static GitHub Pages preview. It publishes the public design and the product catalog only — there is no database here, so there is nowhere to store customers, project requests, support threads, refund decisions or audit records.

The administrator console exists in the full application. To use it:

  1. Run the project locally with ./run_local.sh
  2. Create an administrator: cd server && python3 provision_admin.py
  3. Sign in at http://localhost:8000/admin/
